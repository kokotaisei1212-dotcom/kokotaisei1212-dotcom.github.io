Get a key

When your AI is about to hand a conversation to a person, STK gives permission on the spot, or not, and leaves the evidence.

curl -s https://api.stk-evidence.com/v1/ask -H "Content-Type: application/json" -d '{"conversation_id": "try-1", "intent": "balance.inquiry", "trigger": "unknown"}'

Get your keys

1. The file

Put stk.py (Python 3.8 or later, nothing to install) or stk.mjs (Node 18 or later) next to your AI's code. Set KEY in it to your test key from the email.

2. The two lines

Where your code is about to hand a conversation to a person:

from stk import ask
if ask(conversation_id, intent, "unknown") == "finish":   # your AI is not sure enough: the only trigger STK can permit
    ...  # your AI goes on with the conversation
else:
    ...  # hand it to a person, as your code does today

Node: import { ask } from "./stk.mjs", then if (await ask(conversationId, intent, "unknown") === "finish").

conversation_id: a random id your code makes for each conversation, never your customer's information. intent: one of the 56 ids in The rules. The other four triggers (customer_asked, angry, out_of_scope, authority) always get escalate. Docs

3. Without a file

curl -s https://api.stk-evidence.com/v1/ask -H "X-STK-Key: $STK_TEST_KEY" -H "Content-Type: application/json" \
  -d '{"conversation_id": "c-1", "intent": "balance.inquiry", "trigger": "unknown"}'
